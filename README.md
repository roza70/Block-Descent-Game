# Sai Nanami — Block Descent

A Dr. Stone Sai Nanami themed falling block game built with C++17 and SDL2.

## Features

- Pixel art Sai Nanami sprite with live programmer quotes
- Ghost piece, particle effects on line clears
- Persistent high score
- Pieces named after CS concepts

## Build

```bash
make
./sai_blocks.exe
```

## Controls

| Key        | Action        |
| ---------- | ------------- |
| Arrow Keys | Move / Rotate |
| Space      | Hard Drop     |
| R          | Restart       |
